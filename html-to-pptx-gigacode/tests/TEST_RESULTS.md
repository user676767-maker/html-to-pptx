# Результаты проверок

Дата: 30.10.2026. Использованы только синтетические данные.

## Выполнено

- 10 Python unit-тестов: подготовка демо, отсутствие слайдов, внешние ресурсы, выход за папку ресурсов, удаление скриптов, локальный CSS с импортом/картинкой, циклический импорт, запрет перезаписи, srcset, base. Все прошли.
- Сквозной тест в Chromium 153 в изолированной среде разработки: загрузка автономного HTML через file:// и экспорт через браузерный JavaScript. Автоматизация использовалась только для тестирования здесь, в рабочем проекте её нет.
- Два section.slide преобразованы в два PPTX-слайда. Исходные размеры 1000×680 и 1000×820, общий размер PPTX 10×8.2 дюйма.
- На каждом слайде обнаружены 16 редактируемых текстовых фрагментов. Весь текст совпал с видимым DOM после удаления пробельных различий, включая значения таблицы, кириллицу, проценты и смешанное форматирование.
- Повторный экспорт в одной странице прошёл.
- Нажатие реальной кнопки привело к скачиванию demo.pptx; скачанный ZIP/XML проверен.
- За время загрузки страницы и экспорта зафиксировано 0 HTTP/HTTPS-запросов.
- Скрытый слайд и переполнение рамки вызвали ожидаемую остановку.
- Просмотрены предпросмотр HTML и обе страницы PPTX после импорта/рендеринга через Artifact Tool. Композиция карточек/таблицы сохраняется. Переносы строк в текстах отличаются: это известное ограничение переноса в PowerPoint.

## Не проверено

- Корпоративный HTML, неизвестные CSS, политика конкретного корпоративного браузера.
- Открытие файла в Microsoft PowerPoint: здесь использован другой рендерер, не PowerPoint.
- Произвольные шрифты, сложные фильтры/маски, скрытые презентационные фреймворки, динамические JS-графики.
- Автоматическое обнаружение скилла конкретной версией GigaCode. Предусмотрен запуск с явным чтением SKILL.md.

Это готовая первая версия для локальной проверки, а не гарантия идентичного преобразования любого HTML.
