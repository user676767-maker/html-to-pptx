# HTML → PPTX

Работать в корпоративной среде локально. Не запрашивать отправку исходных файлов наружу. Не использовать интернет, CDN, npx, pip install, npm install, удалённую отладку, другой браузер или изменение политик администратора.

Приоритет: исходная композиция, полное содержание, затем редактируемость. Не сочинять новые заголовки, не сокращать текст, не менять порядок блоков и не создавать дополнительные слайды. Не генерировать новую презентацию по пересказу HTML.

## Выполнение

1. Найти локальный исходный HTML по запросу пользователя. Требовать UTF-8, статические видимые `section.slide`. При отсутствии пути уточнить только путь. Не требовать загрузки корпоративного HTML в чат.
2. Выполнить `python3 --version`. Требуется Python 3.9+. В Windows использовать доступный `python`/`py -3`. Скриптам хватает стандартной библиотеки; Node и python-pptx не нужны.
3. Определить абсолютный путь к этому скиллу. Запустить:

   ```bash
   python3 "<skill>/scripts/prepare.py" "<input.html>" -o "<input-export.html>"
   ```

   Для ресурсов в общей родительской папке добавить `--resource-root "<folder>"`. Указывать только нужную папку проекта. Для известного размера браузерного окна добавить `--viewport-width 1280 --viewport-height 900`. Не менять CSS для принудительной подгонки.
4. Прочитать результат и предупреждения. При ошибке исправлять только подтверждённую причину в отдельной копии. Не устанавливать библиотеки и не подменять отсутствующие ресурсы выдуманными. Если ресурсы внешние, сообщить, какие файлы требуется предоставить локально разрешённым способом.
5. Передать путь к подготовленному HTML. Попросить открыть его в обычном установленном браузере, проверить композицию и нажать «Скачать PPTX». Это необходимый ручной шаг. Не заявлять, что PPTX создан, если создан только HTML.
6. Предложить проверить результат в PowerPoint. Если пользователь сообщает путь к скачанному PPTX, выполнить:

   ```bash
   python3 "<skill>/scripts/validate_pptx.py" "<output.pptx>" --expected-slides <N>
   ```

   Проверка ZIP/XML не заменяет визуальную проверку. Не требовать присылать PPTX наружу. Отчёт экспорта содержит текст слайдов и тоже должен оставаться локальным.

## Поведение

Браузерная библиотека уже находится в `assets/vendor`. Подготовщик проверяет её SHA-256, встраивает библиотеку, CSS и изображения в один HTML. Исходник не перезаписывается. Исходные скрипты удаляются с предупреждением. Встроенная CSP блокирует внешние запросы.

Экспорт использует фактические координаты и вычисленные стили браузера. Презентация имеет общий размер по максимальной ширине и высоте HTML-слайдов. Элементы масштабируются пропорционально, без адаптивного редизайна. Для разных пропорций допускаются поля. Корневое переполнение, скрытые слайды, canvas/video вызывают явную остановку.

Не обещать пиксельную идентичность: переносы строк, шрифты и CSS-эффекты ограничены возможностями библиотеки и PowerPoint. Таблицы могут состоять из отдельных текстов и фигур. SVG/изображения не обязаны быть редактируемыми. Автоматической замены любого неподдерживаемого элемента скриншотом в этой версии нет.

Если браузер запрещает локальные скрипты/скачивание файлов, сообщить об ограничении. Не предлагать отключать защиту. Полностью автоматического режима без участия пользователя в этой версии нет.
